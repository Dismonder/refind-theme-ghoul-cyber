## 🚀 Ghoul Cyber v2.0.0 — Theme Studio, 18 themes, any-distro installer

**🇬🇧 English** · [🇵🇱 Polski](#-polski)

> 🖥️ **Want the easy way?** Get **[Ghoul Cyber – Theme Studio](https://github.com/Dismonder/ghoul-cyber-theme-studio/releases/latest)** — the app built on this release: all 18 themes, live preview, one-click build & install. · **Wolisz prościej?** Pobierz **[Theme Studio](https://github.com/Dismonder/ghoul-cyber-theme-studio/releases/latest)** — aplikację opartą na tym wydaniu.

### What's new
- **Theme Studio** ([separate app](https://github.com/Dismonder/ghoul-cyber-theme-studio)) — pick a theme, tune it with a live preview and build or install it in one click. Polish or English UI, following your system language.
- **18 themes** — the original Ghoul Cyber plus 17 alternative OLED themes (🎭 *fan art*, see below). Each has a generic **LINUX** tile for distributions other than CachyOS.
- **Your screen, your way** (`boot-config.json`) — layout, HUD elements, rEFInd behaviour, own menu entries, how many system tiles are visible, scroll arrows, how many tools are shown.
- **Tile numbers per PC** — no longer baked into the art: numbered by your systems, in your own order, or not at all.
- **Installer for any major Linux** (pacman, apt, dnf, zypper, xbps, apk), also on PCs without Windows. **Installs rEFInd itself** when it is missing (asks first; refuses with Secure Boot on or in legacy BIOS mode).
- **Working tools row** — BIOS, reboot, power off, EFI Shell and MemTest86+ (added automatically), about, boot order, hidden entries; one shared, pixel-identical frame for every tool.
- **Windows** — build and install into rEFInd on the EFI partition (UAC).
- **Hardened** — randomised stress tests (fuzzing) of settings, files and system command output; invalid menu entries can no longer reach `theme.conf`.

### 🇵🇱 Polski

**Nowości**
- **Theme Studio** ([osobna aplikacja](https://github.com/Dismonder/ghoul-cyber-theme-studio)) — wybierz motyw, dopasuj go z podglądem na żywo i zbuduj albo zainstaluj jednym kliknięciem. Interfejs po polsku lub angielsku, zgodnie z językiem systemu.
- **18 motywów** — oryginalny Ghoul Cyber i 17 alternatywnych motywów OLED (🎭 *fan art*, patrz niżej). Każdy ma ogólny kafelek **LINUX** dla dystrybucji innych niż CachyOS.
- **Twój ekran po Twojemu** (`boot-config.json`) — układ, elementy HUD, zachowanie rEFInd, własne wpisy menu, ile kafelków systemów widać naraz, strzałki przewijania, ile narzędzi pokazywać.
- **Numery kafelków pod Twój komputer** — nie są już wypalone w grafikach: według Twoich systemów, Twojej kolejności albo wcale.
- **Instalator na każdego popularnego Linuksa** (pacman, apt, dnf, zypper, xbps, apk), także bez Windowsa. **Sam instaluje rEFInd**, gdy go brakuje (najpierw pyta; odmawia przy włączonym Secure Boot lub trybie legacy BIOS).
- **Działający rząd narzędzi** — BIOS, restart, wyłączenie, EFI Shell i MemTest86+ (dodawane automatycznie), informacje, kolejność rozruchu, ukryte wpisy; jedna, identyczna co do piksela ramka dla każdego narzędzia.
- **Windows** — budowanie i instalacja do rEFInd na partycji EFI (UAC).
- **Odporność** — losowe testy obciążeniowe (fuzzing) ustawień, plików i wyjścia poleceń systemowych; błędne wpisy menu nie trafią już do `theme.conf`.
